# The Last Lantern — Mobile Edition

Это оригинальный проект The Last Lantern 2.0 с поддержкой сенсорного управления. Сюжет, игровой баланс, сохранения и все игровые режимы сохранены.

## Как запустить

- **На ПК:** откройте `index.html` в браузере.
- **На Android / iPhone:** разместите содержимое папки на любом статическом HTTP(S)-хостинге и откройте ссылку в Safari или Chrome. Можно также открыть игру на телефоне по локальной сети через веб-сервер ПК. Для управления **рекомендуется горизонтальная ориентация**.
- Не требуется сборка, npm install или дополнительные зависимости.

### Через Python с компьютера (телефон и ПК в одной сети)

1. Откройте терминал в папке игры.
2. Запустите `python -m http.server 8000 --bind 0.0.0.0` (или `py -m http.server 8000 --bind 0.0.0.0` на Windows).
3. На телефоне откройте `http://IP_КОМПЬЮТЕРА:8000/`.
4. Если подключение не работает, проверьте адрес ПК и настройки межсетевого экрана.

## Сенсорные кнопки

| Элемент | Действие |
|---|---|
| **Левый стик** | Движение с аналоговой силой наклона |
| **АТАКА** (удерживать) | Непрерывная атака; без движения пальца автоприцел на ближайшего врага |
| **АТАКА** (сдвинуть палец) | Прицеливание в направлении свайпа + атака |
| **УМЕНИЕ** | Способность героя; у Пилигрима щит действует, пока кнопка удерживается |
| **РЫВОК** | Рывок по направлению движения (или взгляда, если стик отпущен) |
| **ЗЕЛЬЕ** | Лечение |
| **СКЛЯНКА** | Бросок |
| **АРТЕФАКТ** | Использовать активную реликвию |
| **Ⅱ** | Пауза |
| **Стрелки / OK / ↩** | Перемещение, подтверждение и возврат в меню |
| **▶** (в лагере) | Начать спуск |

Можно одновременно удерживать стик, атаку и умение несколькими пальцами. Также можно касаться игровой области, чтобы наводиться и стрелять. На экране сида доступно поле ввода с экранной клавиатурой.

## Адаптация экрана

- Canvas остаётся логически `960 × 588`, поэтому существующие механики, координаты и игровой HUD не ломаются.
- Размер Canvas автоматически подстраивается под дисплей, соотношение сторон сохраняется.
- В портретной ориентации снизу зарезервирована область под виртуальные контролы, но при маленьком экране текст оригинальных меню может быть мелким. Лучше играть горизонтально.
- Учитываются `safe-area` и `visualViewport`, блокируется прокрутка/масштабирование от случайных жестов во время игры.
- Есть дополнительная строка с текущим здоровьем, маслом, зельями и склянками.
- На компьютере с обычной мышью и клавиатурой ничего не меняется.

## Изменённые файлы

- `index.html` — метатег viewport, контейнеры управления, подключение скрипта.
- `css/style.css` — адаптивная вёрстка и стили кнопок.
- `js/core.js` — подгонка Canvas под экран, сенсорные данные, защита от двойных событий.
- `js/hero.js` — интеграция стика, прицеливания, атаки и удержания умения в игру.
- `js/ui.js` — увеличена зона касаний мелких элементов меню.
- `js/main.js` — синхронизация интерфейса с игровым состоянием.
- `js/mobile.js` — новый модуль Pointer Events и экранная навигация.
- `tests/mobile.js` — тест движения/атаки/рывка/умения.

## Проверки

`node tests/run.js mobile`, `node tests/run.js mechanics`, `node tests/run.js v2`, `node tests/run.js i18n`.

Проверки выполняются без браузера. Визуальную и жестовую проверку на реальном Android/iPhone следует выполнить отдельно: среда разработки блокирует запуск локального сайта в браузере.

## Примечание по сохранениям

Данные хранятся в localStorage того сайта, с которого запускается игра. Перенос на другой домен, протокол или адрес может создать отдельное хранилище — старое сохранение автоматически не переезжает.
