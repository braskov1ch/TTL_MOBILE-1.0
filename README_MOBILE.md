# The Last Lantern — мобильная адаптация

Это полный проект мобильной веб-игры, не APK. Исходные игровые механики и прогресс сохранены. GitHub не изменялся.

## Запуск

Распакуйте архив. В папке проекта выполните:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000` на компьютере. На телефоне в той же Wi-Fi сети откройте `http://IP_КОМПЬЮТЕРА:8000`. Если Windows спросит о доступе, разрешите только для вашей частной сети. При наличии Python на Windows также можно запустить `START_LOCAL.bat`.

Для проверки мобильного интерфейса на компьютере: `http://localhost:8000/?touch=1`.
Прямая загрузка файлов на статический хостинг также поддерживается. Публикацию выполняет владелец проекта отдельно.

## Что изменилось

- Мобильный мир отрисовывается непосредственно в своём Canvas. Копирование и обрезка настольного Canvas удалены из мобильного пути рендера.
- Камера подбирает видимую область по пропорциям окна, плавно следует за героем с небольшим упреждением в направлении взгляда, ограничивается комнатой и сбрасывается при переходе или повороте экрана.
- Отдельный компактный HUD: здоровье, масло в процентах от ёмкости, оберег, глубина/волна, время, ключи, серебро, здоровье босса и уведомления.
- Кнопки показывают запасы, заряды и перезарядку. Управление размещено в собственных зонах, вне игрового поля. В портретном режиме эти зоны находятся снизу.
- Указатели помогают видеть направление к врагам за границей камеры. Карта и список собранных реликвий открываются кнопкой «КАРТА» с паузой игрового процесса.
- Мультитач: левый стик — аналоговое движение; удержание атаки — автонаведение; смещение пальца на атаке — ручное направление. Прицеливаться также можно касанием мира.
- Умение, рывок, зелье, склянка и артефакт обращаются к игровым действиям. Отмена касаний, потеря фокуса и поворот экрана сбрасывают удержания; уход в фон ставит игру на паузу.
- Сенсорные меню используют HTML-кнопки и прокрутку. В выборе героя есть портреты; ввод сида сохраняет фокус; стол Шляпника показывает реальное перемешивание и выбор шляпы по позиции.
- В главном меню есть кнопка полноэкранного режима, если браузер поддерживает его.

## Проверки

```sh
npm test
npm install
npx playwright install chromium
npm run test:browser
```

Первые проверки не требуют npm install. Для браузерного набора нужен Playwright и Chromium. Можно задать `CHROME_EXECUTABLE` с путём к уже установленному Chromium. Сервер для теста запускается автоматически на свободном локальном порту.

Результаты выполненных проверок и ограничения — в `MOBILE_VALIDATION.md`.

## Прогресс

Ключ сохранения `last_lantern_v1` сохранён. Прогресс привязан к браузеру и адресу сайта: локальный запуск не переносит автоматически данные с GitHub Pages. Полное сохранение незавершённого забега не добавлялось; действует исходная система прогресса.
