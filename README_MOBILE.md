# The Last Lantern — Mobile Rework (2.1 UI)

Это не наложение кнопок поверх уменьшаемой ПК-версии. Для устройств с сенсорным вводом игра теперь использует **отдельную разметку мобильного интерфейса**:

- Сцена игры выводится в отдельный Canvas с камерой, которая следует за героем и подбирает масштаб под экран.
- ПК-холст остаётся внутренним источником отрисовки, но не виден пользователю.
- В горизонтальной ориентации игровой мир находится в центре, а левый стик и кнопки действий — **на боковых панелях, вне игрового поля**.
- В портретной ориентации поле сверху, а управление расположено **снизу отдельно от него**.
- HUD с полосами здоровья и масла, ресурсами и паузой находится в самостоятельной верхней панели.
- Главное меню, лагерь, герои, улучшения, лавка, настройки, справочник, бестиарий, хроники, реликвии, достижения, статистика, события, сюжет и результаты игры получили отдельные прокручиваемые HTML-экраны с сенсорными элементами. Сид вводится системной экранной клавиатурой.
- Действия используют оригинальные игровые функции. ИИ, баланс, достижения и сохранения не переносятся в новый движок.
- На ПК остаётся оригинальное Canvas-представление.

## Управление

- Левый стик: движение.
- Атака: удержание — автоприцел, движение пальцем — ручное прицеливание.
- Умение: удержание для защитных умений, нажатие для остальных.
- Рывок, лечение, склянка, активная реликвия: отдельные действия.
- Пауза: кнопка `Ⅱ` на верхней панели.

## Запуск

Можно открыть `index.html` в настольном браузере. Для смартфона разместите папку на статическом хостинге HTTPS (например, GitHub Pages) и откройте ссылку. Никакая сборка не нужна.

## Проверки и ограничения

- `node tests/run.js mobile` — логика сенсорного ввода.
- `node tests/run.js i18n` — RU/EN локализация.
- `node tests/mobile_ui_structure.js` — наличие всех новых экранных блоков и корректный JS.
- `node tests/run.js v2` — известный нестабильный тест выбора одной из трёх реликвий в режиме выживания (существовал до редизайна).

**Реальную проверку жестов и визуальной компоновки на Android/iPhone ещё необходимо выполнить.** Браузер в среде разработки не разрешил открыть даже локальную тестовую страницу, поэтому это не подтверждённый результат плейтеста.

Сохранения через `localStorage` привязаны к домену сайта, на котором открыта игра.
