# The Last Lantern Mobile — публикация через GitHub Pages

В репозитории восстановлены папки js/ и css/. Файл index.html готов для статического хостинга.

## Однократная настройка

1. Откройте Settings → Pages в этом репозитории.
2. Под Build and deployment → Source выберите **GitHub Actions**.
3. При необходимости откройте Actions → Test and deploy The Last Lantern → Run workflow.
4. После успешного развёртывания игра будет доступна по ссылке:
   https://braskov1ch.github.io/TTL_MOBILE-1.0/

При каждом новом push в main workflow запускает проверки и обновляет сайт.
Сайт работает на смартфонах в горизонтальной ориентации. Сохранения в localStorage
не переносятся автоматически между доменами.

## Проверки

В корне проекта: npm test (Node.js 22+).
Также доступны npm run test:assets и npm run test:mobile.

Важно: tests/run.js — облегчённые проверки загрузки, структуры, базовых игровых
систем, локализации и мобильного ввода. Они не заменяют расширенный
исторический набор тестов игрового баланса из исходного архива.
